    • 第 2 步：开通 EdgeOne Pages（1 分钟）

  • 搜索框输入 EdgeOne Pages 并进入

  • 点 立即开通 → 选 免费版

    • 第 3 步：上传网站（3 分钟）

  • 点 创建项目 → 上传文件夹
  • 必须选中以下文件（保持同名，不要改扩展名）：

    • 六、已录入的 V.2027 赛规要点（核对无误）

  • 三级联赛：MFDPL 特级（审核晋升、不占常规席位、不参与降级）/ 一级 / 二级
  • 定级赛：分二键组与摇杆组、不混组；白胎起步、个人刷圈、5 圈取最快；组内前 50% 晋升
  • 原 120% 标准废除 → 统一为杆位圈速 107% 及格线，次级联赛不限
  • 车队制：每赛季 4 队；每队每级至多 3 席；正赛席位每场每队固定 3 个
  • 排位赛 Q1/Q2/Q3：12 人 → 8 人 → 4 人；被淘汰按位置排发车顺位、不重新排序；跳表需二次排位 + 录屏 + 赛会手动计时
  • 积分：25 / 15 / 10 / 8 / 1，最快单圈 +1；未完赛不计分；中途退赛若已具明显领先优势可保留积分
  • 防守 / 让车 / 红旗 / 进站：

    • - 恶意阻挡（停车超 3 秒）→ Dsq

    - 被套圈必须进入缓冲区让车；让车指令不规范双方无责

    - 红旗触发：有效车手 < 4 人 或 黄旗 ≥ 3 次；重启选胎须一致、发车位须一致，违者 Dsq；恶意主张红旗 → Dsq

    - 强制一次进站换胎；禁止全程重复轮胎（红红红 / 黄黄黄），可用白红红、红黄黄等组合

  • 参赛键位：允许摇杆 / 二键，不允许电脑端玩家或连接外设 → 永久禁赛
  • 改动规则限制：私改赛事系统 / 规则 / 群规 → 永久禁赛，仅主办方（繁星）可授权
  • 处罚：梦想驾照 5 分；观察期 1 月 / 半年 / 永久；无期限禁赛可递交检讨书回归；永久禁赛原则上不可回归

    • 七、务必留意的 3 件事

  • qr.png 是占位图：沙盒无法识别图片中的二维码内容。请在微信里把真实群二维码长按保存 → 导出 → 命名为 qr.png 同名替换。
  • 相册 8 张图是程序合成的冰面氛围图：把你的真实比赛截图按 gal-dandong.jpg 等文件名覆盖即可，代码不用改。
